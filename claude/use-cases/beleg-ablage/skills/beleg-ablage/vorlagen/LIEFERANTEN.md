# Lieferanten

Claude lernt hier, wer dir Rechnungen schickt. Jede Zeile ist ein Lieferant. In „Erkennung" stehen, durch Komma getrennt, Merkmale aus Absender oder Beleg (Absender-Domain, ein Textstück aus dem Briefkopf). „Patientenbezug" auf ja setzen, wenn Belege dieses Absenders Daten von Pflegebedürftigen enthalten können (etwa Kostenträger oder Abrechnungsstellen), dann bleiben sie nur lokal.

Du kannst die Tabelle jederzeit selbst ändern. Claude schlägt neue Zeilen vor und trägt sie erst nach deinem Ja ein.
